# 2016–2024 餐飲業前五大困境：人力占三席


- 人員流動率高 51.4%（9 期平均）：招募培訓循環耗損穩定度


- 人事成本過高 50.3%（2018–2024 七期平均）：剛性薪資壓縮毛利


- 人力短缺 42.1%（2018–2024 七期平均）：雙尖峰產能難及時補位
