# 餐飲門市人事成本最適資源配置系統 (M-System)

這是一個以個體經濟推演與門市營運分析為核心的決策支援系統，旨在解決餐飲業「多請一個人到底划不划算」的核心命題。

## 系統架構
本系統採用 Python 進行全自動化 ETL 萃取與清洗，以 SQLite 建構關聯式分析資料庫，並透過 Streamlit 打造互動式決策引擎。

## 目錄結構說明
*   `data/`: 包含原始資料 (raw)、處理後資料 (processed) 以及 SQLite 資料庫 (db)。
*   `docs/`: 存放專案交付之商業簡報、講稿與問答清單。
*   `src/`:
    *   `etl/`: 負責資料清洗、時序對齊與特徵工程的 Python 腳本。
    *   `app/`: Streamlit 決策引擎主程式。

## 核心技術亮點
1.  **PDF 像素座標群聚解析**：免疫政府公開報告格式異動。
2.  **時序特徵對齊 (merge_asof)**：將一次性工資調漲公告轉化為連續成本壓力線。
3.  **邊際損益斷路防禦機制**：精準計算 R1 損益兩平門檻，防止盲目擴張。
